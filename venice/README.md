# Venice city itinerary prototype

Static research build for the 1480 four-pilgrim project. It contains documented visit sequences, graded encounter scenarios, and provisional narrative-interest profiles.

## Evidence model

- **Documented stop:** a place and/or visit is stated in the supplied narrative.
- **Attested co-presence:** the sources place pilgrims within the same managed group or event.
- **Strong scenario:** independent accounts indicate the same restricted place and date or ritual window.
- **Possible scenario:** overlapping residence and common destination, without sufficient timing evidence.

Paths encode narrative order, not exact streets. Pins are approximate anchors on a perspectival historical image rather than modern GIS coordinates.
